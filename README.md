# دارویار (Daruyar)

بات یادآور مصرف دارو در پیام‌رسان بله. این پوشه **اسکلت اولیه‌ی کد** است؛ هدف این است که همه‌ی اعضا از روز اول روی یک ساختار مشترک کار کنند.

> هشدار: کد با خود API واقعی بله هنوز آزمایش نشده است. فقط منطق داخلی (زمان‌بندی، پایگاه‌داده، ارسال یادآور با کلاینت ساختگی) با ۱۹ تست خودکار بررسی شده. اولین کار هفته‌ی ۲: تطبیق `bale_client.py` با مستندات رسمی بله.

## راه‌اندازی (برای هر عضو)
1. Python نسخه‌ی ۳٫۱۰ یا بالاتر.
2. `python -m venv .venv` و فعال‌سازی آن.
3. `pip install -r requirements.txt`
4. `python -m pytest -q` ← باید همه‌ی تست‌ها سبز شوند.
5. هر نفر **بات آزمایشی خودش** را بسازد. فایل `.env.example` را به `.env` کپی کنید و توکن را در آن بگذارید (فایل `.env` هرگز در Git نرود).
6. متغیرها را بارگذاری کنید و اجرا کنید: `python bot.py`

| فایل | کار | مسئول |

| بک‌لاگ، تست پذیرش، مستندات | محصول و فرایند | مدیر محصول |

## قواعد کار با Git
- شاخه‌ی `main` همیشه سالم است (تست‌ها سبز). مستقیم روی آن commit نکنید.
- برای هر کار یک شاخه: `feature/اسم-کوتاه`. پایان کار ← Pull Request ← حداقل **یک نفر دیگر** بازبینی کند ← ادغام.
- پیام commit کوتاه و واضح بنویسید.
- توکن بات، پایگاه‌داده و هر داده‌ی بیمار هرگز در مخزن نرود.
- هر تغییر منطقی باید **تست** داشته باشد.

## تعریف انجام‌شده (Definition of Done)
کد + تست سبز + بازبینی یک نفر + ادغام در main + در جلسه‌ی چهارشنبه دمو شده.
